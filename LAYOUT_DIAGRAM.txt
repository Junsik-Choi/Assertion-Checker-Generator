현재 레이아웃 구조 (최종)
================================

전체 화면 비율:
- 좌측 패널: 20% (고정)
- 우측 영역: 80%
  - 상단: 60% (Input, Output, Condition Signals를 3등분)
  - 하단: 40% (Created Assertions)

┌─────────────────────┬──────────────────────┬──────────────────────┬──────────────────────┐
│  Module / Paths     │                      │                      │                      │
│  (20% 고정)         │      Inputs          │      Outputs         │  Condition Signals   │
│                     │      (2열)           │      (2열)           │      (ms)            │
├─────────────────────┤                      │                      │                      │
│                     │      [1:N]           │      [1:N]           │   name = expr        │
│  Clocks /           │   signal [bits]      │   signal [bits]      │   (Xbits)            │
│  Resets /           │                      │                      │                      │
│  Params             │                      │                      │                      │
│                     │                      │                      │                      │
│  [끝까지 확장]       │                      │                      │                      │
│                     │                      │                      │                      │
│                     ├──────────────────────┴──────────────────────┴──────────────────────┤
│                     │                                                                     │
│                     │              Created Assertions (40% 높이)                          │
│                     │              Type | Signals | Description                          │
│                     │                                                                     │
│                     │                                                                     │
└─────────────────────┴─────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  Status / Command Hints                                                                  │
│  > [Input Prompt]                                                                        │
└─────────────────────────────────────────────────────────────────────────────────────────┘

세부 비율:
- 좌측 패널 (20%):
  - Module/Paths: 상단 일부
  - Clocks/Resets/Params: 하단 끝까지 확장

- 우측 상단 60% (80% 너비를 3등분):
  - Inputs: 약 26.7%
  - Outputs: 약 26.7%
  - Condition Signals: 약 26.6%

- 우측 하단 40%:
  - Created Assertions: 80% 전체 너비 사용
