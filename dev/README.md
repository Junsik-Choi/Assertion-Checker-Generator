# Dev Directory

개발 중에 사용되는 디버그 스크립트와 임시 파일들이 저장되는 디렉토리입니다.

## 파일 구조

- `debug_*.py`: 디버깅 스크립트
- `analyze_*.py`: 분석 유틸리티
- `check_*.py`: 검증 스크립트
- `show_*.py`: 상태 출력 스크립트
- `run_*.py`: 실행 스크립트
- `demo_*.py`: 데모 스크립트
- `prepare_*.py`: 준비 스크립트
- `preview_*.py`: 미리보기 스크립트
- `*.log`: 로그 파일

## 용도

이 디렉토리의 파일들은 다음 목적으로 사용됩니다:

- 프로젝트 개발 중 테스트와 검증
- 디버깅과 상태 확인
- 임시 분석 및 보고서 생성

## 주의사항

이 디렉토리의 파일들은 개발 목적이므로 프로덕션 환경에서는 사용하지 않습니다.
